# App recorte de facturas
Esta es una aplicación diseñada para crear un recorte de facturas especialmente creada para la organización Coreasares.

## Ejecución y Uso
Se este en la misma carpeta donde estan los archivos.

Instalar los requerimientos
```bash
python3 pip install -r requeriments.txt
```
Ejecutar desde la misma terminal.
```bash
python3 app.py
```
Para generar el ejecutable tienes que utilizar el siguiente comando 
```
pyinstaller --noconfirm --windowed --onedir --name "Recorte de facturas" app.py
```
